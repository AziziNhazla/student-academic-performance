# Student Academic Performance

## Project Overview

This project analyzes student academic performance using **Power BI** to explore factors associated with exam scores.

The dashboard focuses on attendance, study hours, access to resources, parental involvement, motivation, teacher quality, family income, peer influence, and tutoring sessions.

## Objectives

- Explore factors associated with student exam performance
- Identify patterns in attendance and study habits
- Compare exam scores across different student and family factors
- Present findings through an interactive Power BI dashboard

## Tools Used

- **Power BI**
- **Power Query** for data cleaning and transformation
- **DAX** for calculated measures

## Dashboard

### 1. Student Academic Performance

The overview page includes:

- Total students
- Average exam score
- Average attendance
- Attendance vs. exam score
- Hours studied vs. exam score
- Exam score by access to resources
- Exam score by parental involvement

### 2. Detailed Student Analysis

The detailed page includes filters and visualizations for:

- Motivation level
- Teacher quality
- Family income
- Gender
- Peer influence
- Tutoring sessions

## Key Insights

- Attendance shows a positive association with exam scores.
- Students with more study hours generally show higher exam scores.
- Higher access to resources is associated with higher average exam scores.
- Exam performance varies across different student, family, and learning factors.

> **Note:** The findings describe patterns and associations in the dataset and should not be interpreted as proof of causation.
